# ⚜️ Maison Violette — Haute Couture & Bespoke Atelier Web Application

A state-of-the-art luxury boutique web application crafted for high fashion houses and bespoke tailoring salons. Built with **React 19**, **Tailwind CSS**, **Vite**, and **Lenis** ultra-smooth momentum scrolling.

---

## ✨ Features

- 🌌 **Luxury Editorial Aesthetic**: Custom curated palette featuring Night Violet (`#120824`), Dark Violet (`#1a0c2e`), and vibrant Dragonfruit (`#FF2A8D`).
- 💎 **Floating Curved Capsule Navbar**: Both ends fully curved (`rounded-full`) with brand logo pill, multi-currency switcher (USD, EUR, GBP, INR, AED), wishlist, shopping bag, and responsive mobile drawer.
- 🎟️ **VIP Privilege Coupon Engine**: Integrated support for VIP code `INDIA 2026` (25% discount) with 1-click apply chips and real-time total recalculations across hero, shopping bag drawer, and checkout.
- ✂️ **Private Bespoke Tailoring Studio**: Interactive 4-step garment customizer (Silhouette cut, Italian velvet / mulberry silk fabrics, hand zardozi embellishments, and measurements).
- 📅 **VIP Fitting & Salon Appointment System**: Complete appointment booking with invitation reference IDs, salon selection (Paris, London, Mumbai, Kolkata), notification badges, and a dedicated **VIP Appointments Drawer**.
- 👗 **Editorial Lookbook & Hotspots**: Interactive runway lookbook with clickable garment detail hotspots and quick-view popups.
- 🛍️ **E-Commerce Concierge**: Cart drawer, wishlist drawer with local storage persistence, free shipping progress tracker, and 256-bit SSL encrypted checkout modal.
- 📱 **100% Mobile & Tablet Responsive**: Optimized touch navigation, zero clashing active states, and mobile-friendly fitting dialogs.
- 🌊 **Ultra-Smooth Momentum Scrolling**: Powered by Lenis for buttery luxury scrolling inertia.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18+ recommended)
- [Git](https://git-scm.com/)

### Installation & Run

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure Environment:**
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```

3. **Start Development Server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

4. **Build for Production:**
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS
- **Smooth Scrolling**: Lenis Smooth Scroll
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **State Management**: React Context API (`ShopContext`) with `localStorage` persistence
